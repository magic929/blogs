# Getting Started

Welcome to the documentation! This guide will help you get started with using this repository.

## What is This?

This is a GitHub Pages site built with Jekyll, designed for writing and organizing documentation, memos, and blog posts.

## How to Use

1. **Writing New Documentation**: Create new markdown files in the `docs/` directory
2. **Organizing Content**: Use subdirectories to organize topics
3. **Formatting**: Use standard Markdown syntax for formatting

## Markdown Basics

- Use `#` for headings
- Use `-` or `*` for bullet points
- Use `**text**` for bold text
- Use `*text*` for italic text
- Use ``` for code blocks

## Adding New Pages

To add a new documentation page:

1. Create a new `.md` file in the `docs/` directory
2. Add front matter at the top:
   ```yaml
   ---
   layout: default
   title: Your Page Title
   ---
   ```
3. Write your content using Markdown
4. Commit and push to GitHub

The page will be automatically published to GitHub Pages!
